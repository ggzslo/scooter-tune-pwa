# Scooter Tune PWA (SoFlow S04 Pro)

Überarbeitete Fassung von [vloyr/Scooter-Tune-PWA](https://github.com/vloyr/Scooter-Tune-PWA) (MIT).

Web-Bluetooth-Steuerung: Sperre, Fahrmodus, Geschwindigkeitslimit.
Benötigt Chrome/Edge (Android, Desktop) oder Bluefy (iOS).

**Hinweis:** In Deutschland sind nach eKFV max. 20 km/h zulässig. Höhere Werte nur auf Privatgelände.
